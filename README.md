# Summit Math 8 ▲

Master **Grade-8 math**, standard by standard — with worked step-by-step solutions (no guessing) and an interactive graph lab. A clean, mature single-file PWA for a ~13–14-year-old. Cornerstone Studio · *Glory to God alone · AMHG*.

## What's inside
- **18 skills** across the five Grade-8 domains, each with an endless, self-computing question generator and a full worked solution:
  - **8.NS** — rational vs irrational, estimating square roots
  - **8.EE** — powers & exponent rules, scientific notation, two-step & both-sides equations, slope, y = mx + b, systems
  - **8.F** — evaluating functions, rate of change & initial value
  - **8.G** — transformations & similarity, angles, Pythagorean theorem, distance, volume (cylinder/cone/sphere)
  - **8.SP** — scatter plots
- **Mastery ladder** (4 in a row), spaced review, and a per-standard dashboard.
- **Graph Lab** — drag sliders for *m* and *b* and watch `y = mx + b` move.

Type numeric answers (with a ± sign key) or pick multiple choice; every miss shows the worked steps. Single `index.html` (ES5) + `manifest.json` + `sw.js` + `icon.svg`; progress in `localStorage`; installable + offline.

## Run / deploy
Open `index.html`, or serve the folder. For GitHub Pages: push to a public repo and enable Pages (`main`, root).
